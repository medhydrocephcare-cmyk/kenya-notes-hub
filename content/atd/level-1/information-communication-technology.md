## 1. Computer fundamentals — hardware

**Hardware** refers to the physical, tangible components of a computer system:

- **Input devices** — keyboard, mouse, scanner — used to enter data into the computer.
- **Output devices** — monitor, printer, speakers — used to present processed information to the user.
- **The central processing unit (CPU)** — often called the "brain" of the computer, it carries out instructions and performs calculations.
- **Storage devices** — hard disk drives, solid-state drives, flash drives — used to store data and programs, distinguished from the computer's temporary working memory (RAM).

---

## 2. Computer fundamentals — software

**Software** refers to the intangible instructions/programs that direct hardware to perform tasks:

- **System software** — the operating system (e.g. Windows) that manages hardware resources and provides the platform on which other software runs.
- **Application software** — programs designed for specific user tasks (word processors, spreadsheets, accounting packages, presentation software).
- **Utility software** — programs supporting system maintenance (antivirus, disk clean-up, backup tools).

---

## 3. Data versus information

**Data** is raw, unprocessed facts and figures (e.g. a list of individual sales transactions) with no meaning on its own until organised. **Information** is data that has been processed, organised and structured so it becomes meaningful and useful for decision-making (e.g. a monthly sales summary report). Good information should generally be: accurate, timely, relevant, complete, and presented in a format the user can readily understand and use.

---

## 4. Common application software used in accounting/business

- **Word processors** (e.g. for letters, reports) — creating and formatting text documents.
- **Spreadsheets** (e.g. for budgets, simple ledgers, calculations) — organising data into rows and columns, with built-in formulas and functions.
- **Accounting/ERP packages** — specialised software for recording transactions, generating financial statements, and managing inventory/payroll.
- **Presentation software** — creating slide-based presentations for meetings and reports.
- **Database software** — storing and retrieving structured data efficiently, useful for managing larger volumes of customer or transaction records.

---

## 5. Spreadsheets for basic accounting tasks

A spreadsheet organises data into a grid of **rows** and **columns**, with each intersection called a **cell**. Common uses in accounting-support work include: simple budgets, basic ledger summaries, loan/interest calculations, and straightforward "what-if" analysis (changing one input to see the effect on a result). Common built-in functions include SUM (adding a range of values), AVERAGE (computing the mean of a range), and simple formulas combining cell references with basic arithmetic operators.

---

## 6. Computer networks, basics

A **network** connects multiple computers to share data, software and hardware resources (e.g. a shared printer). Common types:

- **LAN (Local Area Network)** — covers a small geographic area, e.g. a single office building.
- **WAN (Wide Area Network)** — covers a large geographic area, potentially connecting offices in different cities or countries; the internet is the largest example of a WAN.

Networks allow shared access to files, centralised data storage, and communication tools (e.g. shared email systems) across an organisation.

---

## 7. The internet and email in business

The **internet** is a global network of interconnected computer networks, enabling businesses to communicate, research, advertise, and increasingly, transact online (e-commerce, online banking). **Email** is one of the most widely used business communication tools — fast, provides a written record, but requires care with tone (since non-verbal cues are absent) and with security (phishing attempts often arrive via email).

---

## 8. Information and data security

Protecting business data and information systems involves:

- **Passwords and access controls** — restricting system access to authorised users only, ideally with strong, regularly changed passwords.
- **Antivirus/anti-malware software** — protecting against malicious programs that could damage systems or steal data.
- **Backups** — regularly copying data to a separate location/medium, so it can be recovered if the original is lost, corrupted, or affected by a ransomware attack.
- **Firewalls** — controlling and monitoring incoming/outgoing network traffic to block unauthorised access.
- **User awareness** — training staff to recognise phishing attempts and avoid careless practices (e.g. sharing passwords, using unsecured public networks for sensitive work) since human error is a very common cause of security breaches.

## 9. Full worked question — a simple spreadsheet formula scenario

**Scenario.** A spreadsheet lists five days of sales in cells B2 to B6: 4,000; 6,500; 3,200; 7,800; 5,000 (all figures in KSh).

**Required:** (a) Write the formula that would be entered in cell B7 to compute the total sales for the five days. (b) Write the formula that would be entered in cell B8 to compute the average daily sales. (c) State the resulting values for B7 and B8.

**Solution:**

(a) Formula in B7: `=SUM(B2:B6)`

(b) Formula in B8: `=AVERAGE(B2:B6)`

(c) Total (B7) = 4,000 + 6,500 + 3,200 + 7,800 + 5,000 = **KSh 26,500**

Average (B8) = 26,500 ÷ 5 = **KSh 5,300**

## 11. Marking guide — model answers to the practice examination

**QUESTION ONE**

(a) *(12 marks)* — Hardware is the physical, tangible components of a computer (e.g. keyboard, monitor); software is the intangible instructions/programs directing hardware (e.g. an operating system, a spreadsheet program) — 3 marks each for definition/example set.

(b) *(8 marks)* — System software manages hardware resources and provides the platform for other software to run (e.g. an operating system); application software is designed for specific user tasks (e.g. a word processor or accounting package).

**QUESTION TWO**

(a) *(8 marks)* — Data is raw, unprocessed facts with no inherent meaning (e.g. a list of individual transactions); information is data processed and organised to become meaningful for decision-making (e.g. a monthly sales summary).

(b) *(8 marks — 2 marks each)* — Accurate, timely, relevant, complete (understandable/appropriately presented also acceptable).

(c) *(4 marks — 1 mark each)* — Input: keyboard, mouse (or scanner). Output: monitor, printer (or speakers).

**QUESTION THREE**

(a) *(3 marks)* — `=SUM(C2:C5)`

(b) *(3 marks)* — `=AVERAGE(C2:C5)`

(c) *(6 marks)* — Total = 12,000 + 15,500 + 9,800 + 13,200 = **KSh 50,500**. Average = 50,500 ÷ 4 = **KSh 12,625**.

(d) *(8 marks — 2 marks each)* — Word processor (documents/letters); spreadsheet (budgets/calculations); accounting/ERP package (recording transactions); presentation software (slides for meetings) — database software also acceptable.

**QUESTION FOUR**

(a) *(6 marks)* — A LAN covers a small geographic area (e.g. one office building); a WAN covers a large geographic area, potentially connecting multiple cities/countries.

(b) *(9 marks — 3 marks each)* — Shared access to files; centralised data storage; shared hardware resources (e.g. a shared printer) — shared communication tools also acceptable.

(c) *(5 marks)* — Risk of phishing/malicious attachments; risk of miscommunication due to absence of non-verbal cues/tone (any two, appropriately explained).

**QUESTION FIVE**

(a) *(16 marks — 4 marks each)* — Passwords/access controls; antivirus/anti-malware software; regular backups; firewalls.

(b) *(4 marks)* — Because human error (e.g. falling for phishing, sharing passwords, careless use of unsecured networks) is a common cause of security breaches, so trained, alert users are a key defence alongside technical controls.

## 12. Exam technique and revision checklist

- Hardware vs software questions: always give at least one concrete example alongside the definition — a bare definition without an example often earns partial marks only.
- Spreadsheet formula questions: write the exact formula syntax (e.g. `=SUM(B2:B6)`), not just a description of "adding them up" — precise syntax is usually what's specifically being tested.
- Data vs information: remember information is data that has been processed/organised to become meaningful — this distinction is very commonly tested.
- Security questions: name specific measures (passwords, antivirus, backups, firewalls) rather than a vague "make it secure" — precision earns marks.
- LAN vs WAN: the distinguishing factor is geographic coverage — keep the contrast simple and direct.

**Quick revision — one line per topic:**
1. Hardware = physical components; software = the instructions/programs.
2. System software runs the platform; application software performs specific user tasks.
3. Data = raw unprocessed facts; information = processed, meaningful data.
4. Good information: accurate, timely, relevant, complete, understandable.
5. Spreadsheet basics: `=SUM(range)` totals; `=AVERAGE(range)` computes the mean.
6. LAN = small area network; WAN = large area network (internet is the largest WAN).
7. Email: fast and documented, but watch for phishing and tone/miscommunication risk.
8. Security measures: passwords/access control, antivirus, backups, firewalls, user awareness training.
